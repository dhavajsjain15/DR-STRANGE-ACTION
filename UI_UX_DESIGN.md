# 🎨 UI/UX Design Specification - Dr Strange Action

## 1. Visual Theme
Eldritch Mystic Gold & Fiery Orange particle effects overlaid on dark webcam feeds (`rgb(5, 3, 1)` blend).

---

## 2. Color Palette & Visuals
- **Primary Magic Gold**: `#ffb830`
- **Fiery Orange Embers**: `#ff6b00`
- **Inner Core White**: `#ffffff`
- **Dark BG Blend Ratio**: 55% live image, 45% dark ambient overlay

---

## 3. Web Dashboard Layout (Flask Port 5000)
- **Live Video Canvas**: 16:9 aspect ratio stream container with gold border glow.
- **Gesture Cards**: Visual indicators for Open Palm and Left Fist + Circle.
